# Flashcards (Cloudflare Worker + PWA)

## Deploy
1. Push this folder to a GitHub repo (`wrangler.jsonc`, `src/worker.js`, `public/*`).
2. Cloudflare → Workers & Pages → Create → Import a repository. Use the same Worker name as in `wrangler.jsonc`.
   - If the KV namespace isn't created automatically, run `npx wrangler kv namespace create SYNC` and put the `id` in `wrangler.jsonc`.
3. Worker → Settings → **Variables and Secrets** (runtime, not Build) → add a Secret named `APP_KEY`.
4. Open the Worker URL, enter the same key in the Settings tab, and "Add to Home Screen" on mobile.

## Notes
- Translations, pronunciation and examples are generated by Workers AI.
- Offline: cards live in IndexedDB. Words added offline stay "pending" and are generated and synced when you're back online.
- Intervals: Again 30 min, Hard 1 day, Good 3 days, Easy 1 year. Shortcuts: Space and 1–4.
- apkg: export from Anki with "Support older Anki versions" enabled.
